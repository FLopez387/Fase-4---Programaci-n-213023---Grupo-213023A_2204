# Software FJ – Fase 4 | Programación (213023)

## Descripción
Proyecto colaborativo desarrollado para la Fase 4 del curso Programación (213023) de la UNAD. El sistema permite gestionar clientes, servicios y reservas, aplicando programación orientada a objetos, manejo de excepciones y registro de eventos mediante logs.

## Módulos
- `FASE_4.py`: estructura principal y excepciones.
- `Clase_cliente.py`: gestión y validación de clientes.
- `calculo_costos.py`: cálculo de costos de servicios.
- `servicios.py`: clases y servicios.
- `Reserva.py`: gestión y estados de reservas.
- `config_logging.py`: configuración del registro de eventos.

## Ejecución
Ejecutar el archivo principal `FASE_4.py` desde Python.

## Tecnologías
- Python
- Git y GitHub
- Programación orientada a objetos
- Manejo de excepciones
- Logging
